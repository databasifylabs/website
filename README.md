# databasify.io

Marketing site for Databasify, built with Next.js (App Router), Tailwind CSS and exported as static files.

## Scripts

- `npm run dev` starts the dev server.
- `npm run build` exports the static site to `out/`.
- `npm test` runs the Vitest unit tests.
- `npm run test:e2e` runs the Playwright tests against `out/` (build first).
- `npm run lint` and `npm run typecheck` check the code.

Requires Node 22.
